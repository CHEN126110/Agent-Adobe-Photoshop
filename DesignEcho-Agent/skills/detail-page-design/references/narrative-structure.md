# 详情页叙事结构（店铺 ground truth）

来自真实生产文件（C-1248/PSD/详情页.psb，1440×26418，12 屏）的逐屏解剖。品类实例是袜子；做其他品类时保留叙事骨架、替换卖点内容。

## 样板 12 屏原文（组名即设计决策）

| 屏 | 组名原文 | 叙事职责 |
|---|---|---|
| 1 | 活动营销/品牌背书 *-暂无品牌不去做 | 开场信任——**没有素材就明确跳过，样板自己就这么做** |
| 2 | 产品首屏"穿着展示"+图片icon | 第一眼：产品在使用中的样子 + 核心要点速览 |
| 3 | 模特展示+氛围文案 | 建立向往感 |
| 4 | 主视觉KV图"放大核心利益点" | 一屏只放大一个最重要的利益点 |
| 5 | 材质特点+材质解释和佐证（材质是用户心智） | **用户最关心的信任点**：解释 + 佐证，不是口号 |
| 6 | 产品利益点 | 利益点汇总 |
| 7 | 抗起球处理 | 逐卖点证明（品类实例） |
| 8 | 弹力效果展示 | 逐卖点证明 |
| 9 | 防滑硅胶设计 | 逐卖点证明 |
| 10 | 细节展示（袜口、袜子缝头） | 工艺特写收信任 |
| 11 | 产品规格信息 | 规格/参数 |
| 12 | 模特场景展示 | 场景收尾 |

## 可迁移的判断

- **组名带理由**是店铺的工作习惯：「材质是用户心智」「暂无品牌不去做」——把"为什么这屏这么做/不做"写进组名，是给未来协作者（包括 Agent 自己下一轮）的注释。
- 逐卖点证明屏（7-9）每屏一个卖点、配视觉证据（对比图/演示图/特写），数量随产品卖点数增减。
- 屏与屏之间的素材类型交替（模特/特写/图表）维持浏览节奏，连续同类屏会让人疲劳。
- 换品类自检：把袜子换成任何产品，骨架（信任→展示→氛围→KV→心智→利益→证明→细节→规格→收尾）仍然成立才算用对了框架。
