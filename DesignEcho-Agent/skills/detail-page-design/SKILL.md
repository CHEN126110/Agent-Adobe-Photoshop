# 详情页生产工作法

详情页是**一条说服叙事**，不是图片堆叠。先分流：项目有模板 → 套版（版式主权归模板，只换内容）；无模板 → 按叙事框架从零逐屏设计。深度方法论用 `getDetailPageDesignFramework` 检索；本手册讲店铺的真实组织方式。

## 店铺生产规格（来自真实生产文件）

- 画布宽 **1440**（2 倍稿出 720/750 显示宽），高度按屏数生长（样板 12 屏 ≈ 26000+ 高）。
- **每屏一个顶层组**，命名 `{序号}-{这屏干什么}`——组名写清目的甚至理由（样板原名如「5-材质特点+材质解释和佐证（材质是用户心智）」「1-活动营销/品牌背书 *-暂无品牌不去做」）。**沿用这个命名习惯**：屏的目的写进组名，下轮谁都看得懂。
- 导出按屏切片交付。

## 叙事框架（从样板抽象，品类无关）

```
① 开场信任（活动/品牌背书——没有就明确跳过，不硬凑）
② 产品首屏（使用/穿着展示 + 要点 icon）
③ 氛围屏（模特/场景 + 氛围文案）
④ 核心利益 KV（放大最重要的一个利益点）
⑤ 核心心智屏（材质/成分/技术——用户最关心的那个信任点，解释 + 佐证）
⑥ 利益点汇总
⑦…⑨ 逐卖点证明屏（每屏一个卖点 + 视觉证据，数量按产品定）
⑩ 细节展示（工艺特写）
⑪ 规格信息
⑫ 场景收尾
```

顺序的逻辑：**先建立信任和欲望，再逐点证明，最后给规格收尾**。屏数可增减，顺序骨架保持；每一屏要能回答"这屏让用户信什么"。

## 工作法

1. **认料**：联系表按屏角色归类素材（场景/穿着、细节特写、规格图）；产品事实与卖点列表必须有来源。
2. **定叙事**：按框架列出本次的屏清单（哪些屏做、每屏的卖点与素材），弹卡或对话确认大方向。
3. **逐屏制作**：一屏一组按序号命名；每屏做完读回看图再进下一屏。
4. **收尾**：整页缩略过一遍（节奏、重复、断裂），按屏导出切片，对照交付清单核对。

## 查实的事实要落地

屏清单、每屏卖点来源、模板结构——`updateDesignProjectState` 记下，续跑不重查。
