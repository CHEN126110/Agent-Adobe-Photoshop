# 模板设计细则

## 模板是什么

比较型、系统型设计——建立可复用的组件、间距、编号、备注和变体规则，让 2/3/4 双与自选备注在同一视觉语法中清楚、可比、可编辑。不是"把几张色卡摆上去"。

## 来源降级序列

1. **项目现成**：项目「模板文件」目录里的规格模板。
2. **Eagle 现成**：searchEagleReferences 搜「SKU 模板」「N双装」→ observeEagleAsset 真看 →「合适」分两半：确定的一半自己量（importEagleAssetToProject 导进项目模板目录 → 打开 → inspectTemplateLayout 验证槽位/区域容量与双数一致、画布与色卡尺寸一致或可等比）；判断的一半看图（风格与项目、品牌一致）。**导入的模板必须以含规格的名字落到模板目录**（如「3双装-Eagle候选」）——批量站按文件名里的规格识别模板，无「N双」字样会被判缺模板。Eagle 原件只读，绝不修改。
3. **自行设计**：先看 Eagle 同类参考提取版式关系（不照抄），再从空白新建。不要拿不合适的凑数。

## 设计要点

- 先定共同 token：画布安全区、卡片比例、主体尺度、横纵间距、编号样式、标签位置、备注区、图层命名；再派生 2/3/4 双变体。
- **占位符的间距与位置是设计判断，不是机械均分**：横纵沟槽、边距、卡片占比要画面平衡协调——各卡片视觉重量均衡、留白不挤不散、编号标签与卡片呼应清楚。在模板上看图定稿；批量阶段只消费、不再调。
- 占位符两种机制：图层组占位（严格替换）与矩形占位（区域模型，自动排版，区域间距从模板沟槽量取）。
- 变体间保持同一卡片尺寸体系与视觉语言；数量变化调网格与留白，不重新发明样式。
- 2 双强调同权；3 双避免中间项被误读为主推（除非业务要求）；4 双在单排与 2×2 间按缩略图可辨性选。

## 保存与验收

- 另存为项目「模板文件」目录的新文件，按规格命名（如「3双装-DesignEcho候选」），绝不覆盖参考源。
- 完成判据：结构与占位符复验通过（inspectTemplateLayout 无 blockers），且缩略图下每个同级卡片可识别、视觉重量一致。
- 色卡源文档是只读颜色来源：不在它上面新建图层、占位或文字；其中遗留的隐藏矩形/旧占位不是模板。
