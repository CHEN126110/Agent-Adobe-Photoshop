# SKU 交付核对清单

批量编排收尾时逐项核对。这些是零容差项——规格化生产的答案唯一可校验。

## 数量核对

- [ ] 组合数与确认的规格一致（无漏项、无重复组合）。
- [ ] 每组项数正确（2 双装 2 只、3 双装 3 只……）。
- [ ] 自选备注交付物按约定包含或排除。

## 映射核对

- [ ] 每个颜色与编号来自正确的色卡颜色组，模板槽位无错位、无串色。
- [ ] 组合内颜色顺序与确认卡一致。

## 命名与文件核对

- [ ] 文件名、目录符合项目既有规范（没有规范且将上架时先确认，不静默发明）。
- [ ] 尺寸、格式、保存结果与约定一致。
- [ ] 导出列表读回核对——只有真实读回确认后才能宣称完成。

## 画面核对

- [ ] 不残留占位符、辅助层、隐藏调试层。
- [ ] 缩略图下组合数量一眼可数、颜色可辨。
- [ ] 同批组合图视觉语法一致（间距、编号、标签风格无漂移）。
