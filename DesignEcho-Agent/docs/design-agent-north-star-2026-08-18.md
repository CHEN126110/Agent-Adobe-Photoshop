# 设计 Agent 北极星：从「能排版」到「惊艳」（2026-08-18）

写给设计师看的诊断与路线。不讲代码细节，只讲：现在到底卡在哪、为什么不惊艳、前沿是怎么做的、我们接下来做什么、不做什么。

---

## 1. 现状（真机数据，不是感觉）

- 483 次真实运行里，「完成且真的写了东西」只有 **4%**；78% 的运行零写入。
- 最近一次「成功」的主图（run 472）：**6 分 41 秒、37 次调用、29 次观察、6 次写入**——最终产物是在你自己的 800 文档上加了 **3 行字**，然后把 3 行字缩了缩。
- 昨天到今天 SKU 任务：写了 5–32 层，然后预算耗尽 / 模型欠费 / 报错终止；没有一次出图。

一句话：**Agent 现在是在摸黑操作 Photoshop 的鼠标，不是在做设计。** 它把大部分时间花在「看」（因为看不清所以反复看），把很少的时间花在「做」，做出来的也只是「字放对了位置」。

## 2. 设计师视角：为什么不惊艳

一张惊艳的电商主图，肉眼上由五样东西构成：

| 构成 | 惊艳的来源 | Agent 现在有没有这只手 |
|---|---|---|
| ① 产品本体 | 抠得干净、光影自然、有接触阴影 / 倒影 | 有抠图；**没有阴影、没有精修** |
| ② 场景与氛围 | 背景的材质、光线、色温、道具（木托盘、亚麻布、晨光） | **没有**——只会画纯色矩形 |
| ③ 版式 | 主体大而清、标题住留白、一格一元素 | 有（Agent 声明 regions / blocks，Harness 只做几何执行与越界校验） |
| ④ 字 | 有气质的字体、层级鲜明、字距行距讲究、必要时描边 / 渐变 | 半有（字号比例有，**字体气质 / 图层样式没有**） |
| ⑤ 点缀 | 徽章、价签、保障图标、装饰线——精致不俗 | **没有** |

结论很直白：**惊艳的 80% 来自像素级的光影材质（①②④⑤），而 Agent 手里只有矩形和文字。** 再多的原则、门禁、提示词也变不出光影。这不是「模型不听话」，是「工具箱里没有那把刷子」。

第二个原因是**动作粒度错了**。设计师脑子里的一步是「主体放右下占七成，标题两行放左上，底部一条数据条」；Agent 的一步是「建一个文字层」「移动 40 像素」「截个图看看」。粒度差 20 倍，弱模型（mimo）在 164 个工具里操作 30 多步，必然又慢又乱。

第三个原因是**没有一个说真话的评审**。Anthropic 2026 年 3 月的 harness 文章（Harness design for long-running application development）原话：让模型自评自己的作品，它会「自信地表扬」，哪怕人眼看着平庸；把生成者和评审者分开、把评审者调得挑剔，才有可能拿到能改进的反馈。我们现在的「自看」正是自评，而且用的是弱视觉模型。

## 3. 前沿怎么做（有据可查）

- **Anthropic《Building effective agents》**：最简单的方案 + 组合式模式；工具设计（ACI）与提示词同样重要；每个 harness 组件都是「模型不会 X」的假设，要定期拆。
- **Anthropic《Writing tools for agents》/《Effective context engineering》**：工具要少而高杠杆、按人类专家的思维单位设计；上下文只留高信号 token；「如果人类工程师说不清该用哪个工具，模型也做不到」。
- **Anthropic 2026-03《Harness design for long-running application development》**（前端设计质量专题）：
  - 把主观的「好看」变成可打分的四条：**整体感**（像一件作品而不是零件堆）、**原创性**（有人为决策，不是模板 / AI 味）、**工艺**（层级、间距、色彩、对比）、**功能**（一眼看懂）；权重放在整体感与原创性上，明确惩罚「AI slop」。
  - **生成器 / 评审器分离**；评审器用少样本 + 分数拆解校准；每轮反馈回流；生成器每轮决定「沿着改」还是「换方向」；跑 5–15 轮。
  - 结果：第一轮就比无提示强；到第十轮出现真正的创意跃迁。
- **行业实践（电商图）**：2025–2026 的高质量电商图几乎都是「生成模型出场景 + 真实产品合成 + 可编辑文字」——设计师用 Nano Banana Pro / Seedream / Flux 出氛围，在 PS 里合成、排字、批量。没有人靠 LLM 摆矩形做出惊艳。

## 4. 我的主张（三刀，按顺序）

### 第一刀：一次成稿的「制作车间」——`composeDesign`

把「首稿」从 30 多步的摸黑操作，改成 **一次调用**：模型像艺术总监一样给一张「设计稿」（画布、背景方向、主体素材与占比、配方、文案、色板、字体气质），车间一口气做完：

1. 建画布
2. 背景：纯色 / 渐变 / 素材库图 / **生成的场景底**（用产品照片作参照，生成同光线同氛围的空场景——产品本体永远用真实图，不生成）
3. 真实产品抠图置入、主体感知缩放、**接触投影**
4. Agent 声明版面与文字工艺，Harness 生成可编辑文字层
5. 回读快照 + 结构，交回模型

目标：一张主图 ≤ 60 秒、≤ 3 次模型调用（现在 6–8 分钟、30+ 次）。这不是「限制创意」——配方可增、背景方向由模型写、占比颜色字体模型给；限制的只是「徒手摆坐标」这件没有创意价值的事。

**原则（我拍板，你可以否）**：产品本体永远真实（不生成，不变形）；场景 / 背景允许生成；文字永远可编辑。

### 第二刀：说真话的「评审器」

独立的评审步骤，用最强的视觉模型（不是 mimo），四条标准（整体感 / 原创性 / 工艺 / 功能）+ 电商硬项（文案有来源、字不压主体、主体够大、导出尺寸对），输出**分数 + 具体的可执行批评**（「标题压腿」「背景 AI 味紫渐变」「主体太小」），生成器据此改稿最多 3 轮。评审器用你 Eagle 库里的好图 / 差图做少样本校准——**这一步需要你**：挑 5 张你觉得惊艳的、5 张你觉得不行的，说一句为什么。

### 第三刀：看得见的质量基线——「画廊评测」

10 条真实 brief（你的项目、你的素材），每次改动跑一遍，出一张网页画廊（缩略图 + 评审分 + 耗时）。**你用眼睛判断有没有变好**，不用读日志、不用信 smoke。这也是止住「一天十八刀补丁」的唯一办法：改动有没有用，画廊说了算。

## 5. 不做什么

- 不再往系统提示里加原则；不再加门禁 / 表单 / 预算规则治「做不好」。
- 不动主循环结构；车间与评审器都是循环外的独立模块 + 一两个高层工具。
- 不用生成模型替代产品本体；不承诺「一次就惊艳」——承诺的是：首稿在 1 分钟内达到「结构对、有氛围、有主次」，评审 2–3 轮后稳定进入「像样」，惊艳由参考、校准与迭代逼近。

## 6. 诚实的边界

- 生成场景依赖 OpenRouter（Gemini 3 Pro Image）/ Seedream 的可用性与余额；不可用时车间退回纯色 / 渐变 / 素材库背景，仍能出稿。
- 主力模型 mimo 的判断力是天花板之一；车间把 30 步压成 1 步、评审器用强模型，是在这个天花板下拿到最多的收益。换更强的主模型，收益叠加。
- 「惊艳」最终由人拍板；本文的所有承诺都是可度量的中间指标。

## 7. 本周落地顺序

1. `composeDesign` v1（背景四式 + 主体投影 + 配方 + 回读）——真机出一张主图并计时。
2. 评审器 v1（四条标准 + 硬项 + 少样本校准表）。
3. 画廊评测 v1（10 条 brief、一张网页）。
