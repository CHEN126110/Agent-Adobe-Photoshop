# Agent / Harness 边界判定与专业建议（2026-08-18）

> **状态：历史判定稿。** 2026-08-21 已进一步把 Experience Publisher、Design Kernel、Skill overlay、Evaluation 和模型窗口从宽泛的 Harness 概念中拆出独立语义 owner。当前边界以 `project-memory/Prompt.md` 与 `docs/design-agent-operating-system.md` 为准；本文不再指挥生产实现。

本文目的：记录当时按行业定义对组件的归位和问题诊断。它仍可说明“不要让规则替 Agent 判断”，但其中任务卡常驻、评价常开和用户必须先提供固定数量校准样本等建议已经退役。

## 1. 行业定义（不是我们发明的）

| 层 | 定义（Anthropic《Building effective agents》《Writing tools for agents》《Effective context engineering》《Harness design for long-running apps》，OpenAI Agents 指南同口径） | 归谁 |
|---|---|---|
| **Agent（模型 + 循环）** | 在环境反馈下自主决定下一步的模型：理解目标、规划、选工具、判断结果、决定继续 / 换向 / 停止 | 判断力、创意、取舍 |
| **Harness（脚手架）** | 让模型能把事做成的一切非模型部分：①工具 / ACI（粒度对、描述清、返回有信息）②环境与观察（看得到该看的、算得准该算的）③记忆与上下文（高信号、按需、可续跑）④评估与验证（独立评审、测试、事实核对）⑤权限与护栏（安全边界，不是流程门禁）⑥编排（子代理、生成器 / 评审器分离） | 能力、证据、精度、底线 |
| **不属于任何一层的东西** | 替模型做判断的规则、按症状加的门禁、写死的流程与默认 | 应删除或搬到数据层由 Agent 选用 |

一句判据（用户认可的三问）：**这个改动是在替 Agent 做判断吗？是它缺的一条能力或证据吗？换成海报 / 详情页还成立吗？**

## 2. DesignEcho 现状归位

### 2.1 没偏（底座在）
- **工具 / ACI**：`composeDesign`（一次成稿、自由构图）、`renderLayout`、`fitLayerSubjectToRegion`、主体框（素材属性）、`planPhotoFullBleedPlacement`（放多大放哪的几何）——粒度已从"摆坐标"抬到"艺术总监下单"。
- **观察 / 证据**：主体框、对不对核对器（事实表 / 文案一致 / 模板来源）、运行事实账本、导出图贴回对话。
- **评估**：`evaluateDesign` 独立评审（四标准 + 硬项 + 对照设计说明）、画廊评测。
- **记忆 / 学习**：候选隔离与人审出口已经存在；任务卡只是复杂任务的可选工作笔记，不是 Memory，也不是每个任务的完成门禁。
- **编排**：生成器 / 评审器分离已成形；Skill 是数据层可选能力（用户可自建）。

### 2.2 偏了（要收）
| 偏离 | 表现 | 处置 |
|---|---|---|
| Harness 替 Agent 做设计判断 | 我今天写过"生成式默认 / 摄影优先默认"；早期的固定 8 屏 / 11 屏、品类专属提示 | 改为"两条路并列，Agent 选并说出为什么"；品类内容住数据层 |
| 症状驱动的门禁与规则 | v5 stage 机写入门禁（已拆）、观察预算拦截（已改提醒）、表单驳回循环（已改）| 继续只减不增；棘轮盯着 |
| 业务流程脚本化 | sku-batch 5000+ 行执行器把判断和执行揉在一起 | 判断（组合、模板合不合适、文案对不对）交回 Agent + 核对器；执行器只做确定性排版与导出 |
| 评审 / 校准缺"品味种子" | 评审器四标准通用，还没有用户的好 / 差样本 | 用户给 5 好 5 差，进候选区作校准 |
| 视觉证据弱 | 视觉模型槽 mimo，评审与看参考的天花板 | 换强读图模型（设置项，不动代码） |

### 2.3 "修手"不算打地鼠
图层组读回误判、写入身份泄漏、工作流交回死循环——这是手坏了。修手不是替 Agent 判断，但修完必须回到能力建设，不在原地加规则。

## 3. 专业建议（按优先级）

1. **把"判断"从 Skill 执行器里抽回 Agent**：SKU / 详情页流程只保留确定性排版与导出，"要不要重做模板 / 组合怎么配 / 文案对不对 / 图选哪张"由 Agent 用任务卡 + 核对器 + 评审器决定。这是最大的一处偏离，也是"Agent 会设计"的关键。
2. **评审器校准 + 合适的视觉模型**：这是独立质量反馈能力，不是 Agent 品味的唯一来源，也不应成为开放首稿写入门票。
3. **文案底层思维**：通用方法进入 Design Kernel / Knowledge；只有可证明的商品事实、合规与来源错误可成为硬项，语气、长度和表达是 Brief-relative 的专业判断。
4. **画廊评测常态化**：每次改动跑一次；分数不涨的改动不算改进。
5. **反思器与 Agent 自写 skill**：等评审器稳了再做（燃料齐了才有意义）。
6. **凡新增前置拦截 / 默认值 / 品类词**：先过三问；过不了不动代码。

## 4. 不做什么
- 不为单次失败加门禁；不写品类专属流程进 Agent；不再用"默认"替设计师定风格；不拿 smoke 假绿当验收；不承诺"一次就惊艳"。
