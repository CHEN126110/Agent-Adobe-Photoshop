# 单画布视觉设计能力：治理结论与真实验收规范

> 状态：`contract_ready / live_not_verified`
>
> 日期：2026-07-26
>
> 适用能力：`design.single_canvas_visual` / `design.single_canvas_visual.v1`

## 1. 核心判断

本项目不应新增一个“海报专用固定流程”。海报、活动 KV、社媒封面和 Banner 的共同本质，是在单一画布中根据目标、内容、素材、渠道与尺寸动态建立视觉传播方案。

因此第四个专业 Skill 定义为：

```text
design.single_canvas_visual
```

海报只是它的第一个真实验收样本，不是独立执行器、关键词路由或固定模板。

这项判断保留了治理方案的正确部分，同时补充三条现实约束：

1. Model 负责理解、取舍、规划和视觉判断；Harness 负责证据、权限、状态、预算和完成门禁。
2. 动态规划不等于放弃确定性约束。写入权限、读后写、改后必看、交付收据必须在执行点强制。
3. 当前瓶颈不是继续增加架构名词，而是把一次真实设计从用户目标可靠地闭环到 Photoshop 成品。

## 2. 能力边界

### 应该具备

- 根据用户目标声明具体 Task Type，而不是依赖本地海报关键词。
- 读取用户提供的素材、文案、品牌信息、渠道和画布约束。
- 动态形成内容策略、艺术方向、构图、层级、字体、配色与质感方案。
- 自主选择必要的 Photoshop 原子工具并创建可编辑图层。
- 每次关键写入后重新观察同一文档历史状态。
- 根据质量断言决定通过、补观察、有限返工或升级用户，而不是自由口述完成。
- 保存可编辑文档、导出预览，并形成可核验的交付记录。

### 不应该具备

- 在 Agent 核心中增加“海报”关键词分支。
- 新增 `poster.executor.ts` 或把固定工具顺序写入 Manifest。
- 把固定版式、固定图层数量或固定审美风格当成能力本身。
- 将工具返回 `success`、模型说“完成了”或一张过期截图当成验收通过。
- 在缺少素材观察、最终视觉复核或交付收据时宣称任务完成。

## 3. 目标运行链路

```text
用户目标
  → R0：模型声明 design.single_canvas_visual.v1
  → R1：形成可追溯 Brief，记录必含内容、渠道和画布约束
  → R2：观察用户实际选定的素材，并绑定素材身份与证据
  → R3：动态生成内容、艺术方向和布局计划
  → R4：形成有依赖、有预算、可恢复的动作图
  → E1：通过 Photoshop 原子工具执行，并对写入目标做读回
  → R5：对最后一次写入后的同一版本重新看图、评分和有限返工
  → E2：保存可编辑文档、导出成品并签发 Delivery Receipt
```

R4 当前仍是 `shadowOnly`，`schedulerAuthority=false`。在满足本规范第 8 节的启用阈值前，不得把它描述为已接管调度、重试或去重。

## 5. 上线前 P0 缺口

### P0-1：R2 证据必须绑定用户选择的素材

当前通用读取成功可能只证明 Agent 看过某个文档或快照，尚不足以证明它看过用户指定的 `asset_source`。

通过条件：

- 观察证据包含素材身份、来源、文档身份和观察时间。
- R3 只能消费与当前 Brief 所选素材一致的证据。
- 素材发生替换后旧证据自动失效。

### P0-2：最终复核必须绑定最后一次 Photoshop 写入

当前写后读回主要能绑定文档，仍需稳定绑定被修改对象、文档版本或等价历史标识。

通过条件：

- 最终视觉快照晚于最后一次写入。
- 快照、结构读回和评分属于同一文档历史状态。
- 过期截图不能推动 R5 或 E2。

### P0-3：通用 Delivery Receipt

普通 `saveDocument` / `exportAsset` 尚未形成所有 Manifest-native 设计能力都可消费的统一交付收据。

通过条件：

- 收据记录可编辑文档、导出文件、尺寸、格式、文档身份和最终复核版本。
- 保存或导出失败时 E2 不得通过。
- UI 只展示真实存在且可定位的交付物。

### P0-4：统一 Release Gate

需要一个单一 owner 的发布门禁，综合检查：

- Brief 必含内容覆盖；
- 输入素材观察；
- 写入与写后读回；
- 最终新鲜视觉复核；
- 质量结论；
- Delivery Receipt。

`req.brief-coverage` 已阻止视觉判官在无法核对时直接通过，但它不能替代文字图层读取、OCR 或结构化内容比对。明确的 `must_include` 仍需确定性覆盖检查。

## 6. 真实验收样本

首轮使用至少 20 个单画布金标任务，不能只测一种版式：

- 促销海报：有标题、日期、价格、行动信息和商品素材。
- 活动 KV：强调主题氛围、品牌调性和主视觉。
- 社媒封面：强缩略图识别和安全区约束。
- 横幅 Banner：宽画布、短阅读路径和多端适配。
- 纯文字活动海报：无商品主体，考察动态构图能力。
- 多素材海报：考察素材选择、层级与遮挡关系。
- 素材不足任务：应提出最小必要确认或诚实降级，不能编造。

每个样本保存：

- 用户原始目标与结构化 Brief；
- 所选素材和视觉观察证据；
- 动作与 Photoshop 写入记录；
- 写后结构读回和最终快照；
- 质量断言、返工记录与停止原因；
- PSD、导出文件与 Delivery Receipt；
- 设计师盲评结论。

## 7. 预期效果与上线指标

### 路由与规划

- Task Type 正确声明率 ≥ 95%。
- 误路由到主图、详情页或 SKU 的比例 ≤ 2%。
- 本地海报关键词分支数量 = 0。
- 固定版式或固定 Photoshop 调用顺序数量 = 0。

### 执行可靠性

- 未授权或计划外写入 = 0。
- 写后目标绑定率 = 100%。
- 过期截图被接受 = 0。
- “工具成功即设计完成” = 0。
- 明确 `must_include` 遗漏后仍通过 = 0。
- 默认最多 1 次自动修订，硬上限 3 次；到达上限必须诚实停止或升级。

### 设计质量

- 至少 20 个金标样本。
- 阻断级问题召回率 ≥ 90%。
- 质量门禁误通过率 ≤ 5%。
- 视觉判官与专业设计师结论一致率 ≥ 80%。
- 至少 80% 样本达到“无需返工或只需轻微返工即可使用”。

### 效率

- 首个可见草稿：P50 ≤ 4 分钟，P90 ≤ 7 分钟。
- 可交付结果：P50 ≤ 10 分钟，P90 ≤ 15 分钟。
- 以上时间只统计真实 Photoshop 运行，不以 mock 或离线 smoke 代替。

## 8. R4 从影子模式转为调度权威的阈值

以下条件全部满足前，保持 `shadowOnly=true`：

- ≥ 12 次真实运行，覆盖至少 3 类设计 Skill。
- ≥ 100 条动作观察，其中至少 5 条真实失败路径。
- 动作节点归因完整率 ≥ 97%。
- 重复动作率 ≤ 1%。
- 非法依赖跳过率 ≤ 0.5%。
- 可恢复失败的恢复成功率 ≥ 95%。
- Photoshop 写后目标绑定率 = 100%。
- 丢失观察记录 = 0。

达到阈值后也应先灰度启用，不直接替换当前 v3 自主循环。

## 9. 状态判定

当前状态为：

```text
contract_ready
├─ Manifest / Knowledge / Evaluation / R0 catalog：完成
├─ 离线契约与类型检查：通过
├─ Photoshop 实机端到端：本轮未验证
└─ live_ready：否（受第 5 节四项 P0 缺口阻断）
```

只有完成真实 Photoshop canary、留存完整证据并达到第 7 节门槛后，才能把状态改为 `live_ready`。
